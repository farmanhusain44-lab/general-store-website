# General Store Website

A simple responsive landing page for a general store offering daily-use products and doorstep delivery.

## Run locally

Open index.html in a browser, or serve the folder with a simple static server.

## Prepare for publishing

- Replace the placeholder `https://your-domain.com/` in `index.html`, `sitemap.xml`, and `robots.txt` with your real domain before publishing.
- Quick local preview with Python:

```bash
python -m http.server 8000
```

## Deploy (GitHub Pages)

1. Initialize git, commit, and push to a GitHub repo.
2. Enable GitHub Pages from the repository Settings → Pages, select the `main`/`gh-pages` branch and root folder.

Or use Netlify/Vercel for automatic deploys from a connected Git repository.
